# SkillSwap / 技遇

AI-powered Skill Exchange prototype built with Next.js + Tailwind CSS + Lucide Icons.

## Local run
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: Next.js (auto-detected).
4. Deploy. Keep the same Vercel project/domain for later iterations.

No environment variables or backend are required.
